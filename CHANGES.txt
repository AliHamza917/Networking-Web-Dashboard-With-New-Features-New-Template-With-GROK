FIXES (cumulative: includes everything from the first fix zip)
=============================================================
Copy the "cisco-config-dashboard" folder from this zip over yours. It replaces 4 files and adds 1:
    cisco-config-dashboard/templates/index.html
    cisco-config-dashboard/app/main.py
    cisco-config-dashboard/desktop_app.py
    cisco-config-dashboard/app/desktop_api.py      (new)
Your data/ folder is NOT touched. Restart the dashboard (and the desktop app) and press Ctrl+F5 in the browser.

THIS ROUND
  1. Switch Monitor now shows ONLY downtime:
       - while a device is down:   "Down for 2m 10s"
       - once it is back up:       "Last downtime 4m 10s" with the time it went down and came back
         (hover it for the last 5 outages)
     Removed: Uptime, Total down, Total up, Avail, Outages, and the summed totals.
     Time while monitoring was not running is never counted as downtime.
     (Old statistics are discarded - they are stored under a new key.)
  2. Only one browser tab can use the dashboard at a time. A second tab shows
     "Dashboard is already open in another tab" with a button "Use this tab instead".
     Closing the active tab frees the other one automatically.
     Opening /login while already signed in goes straight to the dashboard.
  3. Backup running-config now works in the desktop app: it opens the native "Save as" window.
     (Normal browsers still download the file as before.)

EARLIER ROUND
  - IP Scanner and SSH Setup buttons restored (their functions had been removed from index.html).
  - Alerts always visible in the page; dashboard-server restarts are not counted as a switch being down.
